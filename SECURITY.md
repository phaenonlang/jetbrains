# Security policy

Report a vulnerability in the plugin privately, through GitHub's private vulnerability reporting:
**Report a vulnerability** on this repository's
[Security tab](https://github.com/phaenonlang/jetbrains/security/advisories/new). Please do not
open a public issue for it.

Say which plugin version and which IDE and version are affected, how to reproduce it, and what it
lets an attacker do. The fix ships in a new release of the plugin, and the advisory is published
with it. Before 1.0, only the latest release gets fixes.

A vulnerability in the compiler, `phn`, which the plugin runs for diagnostics, build on save and
Reformat Code, belongs to [phaenonlang/phaenon](https://github.com/phaenonlang/phaenon): report it
there the same way.
