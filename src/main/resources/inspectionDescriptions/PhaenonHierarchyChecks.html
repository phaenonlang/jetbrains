Reports a method that is not compatible with a method it overrides or implements, when either side has a type the Phaenon compiler erases: a type parameter, list<T>, map<K, V>, class<T>, a tuple or a closure type.

PhpStorm's own hierarchy check sees no declared type where Phaenon erased one, so it would read save(T $aggregate) as save(mixed $aggregate). This check reads the parent's signature as the child sees it, with the type arguments written on its extends and implements clauses, and compares parameters and return types as PHP and the Phaenon checker do.
